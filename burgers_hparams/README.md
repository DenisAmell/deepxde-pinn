# Анализ гиперпараметров PINN для уравнения Бюргерса

Базовая конфигурация — пример DeepXDE `examples/pinn_forward/Burgers.py`: 3 × 20, tanh, Glorot normal, 2540 точек Hammersley, Adam 15 000 итераций (lr = 1e-3) → L-BFGS.

## Серии экспериментов

| Серия | Что меняется | Конфигураций |
|---|---|---|
| одиночные изменения | слои, нейроны, сетка «слои × нейроны», активация, инициализация, число и расстановка точек, точки границы и t = 0, RAR, пересэмплирование, оптимизаторы, итерации Adam, шаги L-BFGS, lr | 62 |
| комбинации | активация × инициализация, активация × оптимизатор, 13 готовых конфигураций | 37 |
| устойчивость | базовая модель на 10 seed во float32 и float64 | 17 прогонов |

80 конфигураций запущены с 3 разными seed. Метрика — относительная L2-ошибка на эталонной сетке 256 × 100 (`../burgers/Burgers.npz`), по 3 seed — среднее геометрическое.

## Файлы

| Файл | Назначение |
|---|---|
| `run_experiments.py` | все эксперименты; пропускает уже посчитанные |
| `bench_time.py` | честный замер времени: мс на итерацию для каждой конфигурации по очереди |
| `make_figures.py` | графики (`figures/`), `summary.md`, `tables.json`, `stability.json` |
| `results/*.json` | метрики каждого прогона (L2, макс. ошибка, невязка, шаги, параметры) |
| `results/*.npz` | предсказание на сетке, история потерь, точки обучения |
| `results/timing.json` | замер времени итераций |

## Запуск

```bash
python run_experiments.py --workers 9
python bench_time.py
python make_figures.py
```

Расчёт идёт на CPU, по одному потоку на процесс. DeepXDE по умолчанию выбирает GPU Apple (MPS), но для такой маленькой сети процессор в несколько раз быстрее. Полный пересчёт всех 276 прогонов на Apple M4 занимает около 3.5 часов.
